### 📌 Featured Project

#### [AI Stock Market Intelligence Terminal](https://github.com/Prathamesh-000/AI-Stock-Market-Intelligence)

> A Bloomberg Terminal-inspired AI platform that predicts stock market impact from financial news in real-time.

**Key Features:**
- 🧠 GPT-4o-mini NLP pipeline for structured news analysis
- 📊 XGBoost models trained per ticker (NVDA, AMD, AAPL, TSLA, MSFT)
- 🔍 RAG vector store for historical news similarity
- ⚡ Live prices via yfinance + RSS news feed
- 📈 Interactive 1D/1W/1M charts with hover scrubbing
- 🎯 5-dimensional scoring: Impact, Sentiment, Confidence, Volatility, RAG
